# Entry Map

Panasia가 원하는 프로젝트에게 먼저 보내는 **업체별 맞춤 아시아 진입 지도**입니다. contact form 대신 이 페이지 링크를 보냅니다.

받은 쪽은 페이지에서 직접 체험합니다.

1. **지금의 위치**: 자기 프로젝트의 현재 상황을 Panasia가 읽은 결과
2. **같은 길을 간 프로젝트**: Panasia 실제 사례(panasia.io 공개), 같은 분야부터 표시
3. **8개 시장 적합도**: 점수, 막히는 조건, 시장 넣기/빼기
4. **플레이북과 견적**: 플레이북마다 근거 사례가 붙고, 고르면 견적이 실시간 계산
5. **진입 순서**: 단계 진입 또는 동시 진입에 따른 12개월 일정
6. **다음 단계**: 구성 그대로 Entry Review 요청 문구 복사

## 새 업체용 페이지 만들기

1. `index.html`을 `entry/{프로젝트명}.html`로 복사합니다.
2. 파일 아래쪽 `<script>` 안의 `BRIEF` 객체만 교체합니다. 프로젝트 정보, 분야(`sector`), 기본 플레이북, 현재 지표, 시장별 점수와 막히는 조건이 들어갑니다.
   - `CASES`(실제 사례)와 `PLAYBOOKS`(플레이북·단가)는 모든 업체가 공유합니다. 새 사례가 생기면 `CASES`에 추가하세요.
3. 링크를 보냅니다.

## 현재 상태

- `CASES`의 사례와 수치는 panasia.io에 공개된 실제 기록입니다(검색으로 수집, 사이트 원문과 대조 필요).
- 대상 프로젝트(Halcyon Finance), 시장 점수, **플레이북 단가는 샘플**입니다. 실제 발송 전에 교체해야 합니다.
- 시장 점수 가중치는 `W` 상수(규제 25%, 거래소 25%, 수요 30%, 파트너 20%)에서 조정합니다.
- KO/EN 전환을 지원합니다.
