# Entry Map

Panasia가 원하는 프로젝트에게 먼저 보내는 **업체별 맞춤 아시아 진입 지도**입니다. contact form 대신 이 페이지 링크를 보냅니다.

받은 쪽은 페이지에서 직접 체험합니다.

1. **지금의 위치**: 자기 프로젝트의 현재 상황을 Panasia가 읽은 결과
2. **8개 시장 적합도**: Panasia Intelligence 점수, 막히는 조건, 시장 넣기/빼기
3. **진입 순서**: 단계 진입 또는 동시 진입에 따른 12개월 일정
4. **견적**: 선택한 시장과 범위에 따라 실시간 계산
5. **협업하면 열리는 것**: 연결 가능한 거래소, 파트너, 커뮤니티 규모
6. **다음 단계**: 구성 그대로 Entry Review 요청 문구 복사

## 새 업체용 페이지 만들기

1. `index.html`을 `entry/{프로젝트명}.html`로 복사합니다.
2. 파일 아래쪽 `<script>` 안의 `BRIEF` 객체만 교체합니다. 프로젝트 정보, 현재 지표, 시장별 점수와 막히는 조건, 단가가 들어갑니다.
3. 링크를 보냅니다.

## 현재 상태

- 프로젝트(Halcyon Network)와 **모든 수치·단가는 샘플**입니다. 실제 발송 전에 Panasia Intelligence 데이터와 Panasia 단가표로 교체해야 합니다.
- 시장 점수 가중치는 `W` 상수(규제 25%, 거래소 25%, 수요 30%, 파트너 20%)에서 조정합니다.
- KO/EN 전환을 지원합니다.
