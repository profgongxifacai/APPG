# Panasia Scope Room (판아시아 스코프 룸)

contact form 대신, 방문자가 **첫 통화 전에 판아시아의 방식으로 자기 회사의 첫 스코프를 직접 그려 보는** 체험형 제품입니다. 판아시아의 공개 실적과 출처가 있는 조건만 씁니다. 체험은 최대한 열어 두고, 실명·최종 가격·전문가 의견 같은 디테일은 딜이 진행된 뒤(Entry Review)에 다룹니다.

- `index.html`: 현재 버전(v3). 단일 HTML 파일이며 백엔드가 없습니다.
- `v2.html`: 이전 Entry Map 프로토타입.

## 들어오는 길 (해시)

| 주소 | 화면 |
|---|---|
| `index.html` | 세 개의 문: ① 아시아 진출 블록체인 기업 ② 기술이 필요한 기업을 찾는 쪽 ③ 블록체인 도입 기관 |
| `#rwa` `#defi` `#infra` `#exchange` `#ai` `#depin` `#wallet` `#institution` `#bank` `#payments` `#mobility` | 캠페인 링크. 첫 답이 미리 선택된 상태로 시작 |
| `#demo` | 가상의 예시 기업(Halcyon Finance)용 맞춤 페이지 |
| `#P2-…` | Plan ID. 받은 사람은 같은 플랜을 검토 모드로 엽니다 |

## 기본 흐름 (v4: 3분 경로)

1. **표지**: 세 개의 문과 panasia.io 공개 실적.
2. **세 가지 질문**: 분야(또는 기관 유형) · 가장 원하는 결과(또는 풀고 싶은 문제) · 시점. 누를 때마다 미리보기가 바뀝니다.
3. **진입 브리프**: 결론 한 문장, 첫 시장과 이유, 가장 가까운 공개 사례 3건, 추천 프로그램 2개, 판아시아가 먼저 확인할 것, 일정, 그리고 "30분 무료 상담 잡기".

맞춤 페이지(`#demo`, prospect 사본)는 첫 화면 한 장(판단 · 사실 3개 · 제안 경로 · 제안 프로그램 · 상담)으로 끝납니다. 아래의 전체 도구는 "더 깊이 보기" / "제안 직접 조정해 보기"를 누르면 열립니다.

용어: 30분 무료 상담 → 진입 진단(유료, 2~3주) → 첫 시장 런칭(약 90일). 기본 화면의 출처 표기는 "공개 실적"과 "예시"만 보이고, "출처 보기"를 켜면 다섯 가지가 모두 보입니다.

## 더 깊이 보기 (전체 도구)

1. **§0 표지**: 세 개의 문, panasia.io에 게시된 실적, 출처 표기 범례. 맞춤 페이지에서는 "작성 대상", 판아시아의 판단, 사실 확인(맞음/오래됨/틀림)이 나옵니다.
2. **§1 위치**: 5번 탭. 탭할 때마다 매칭 사례, 시장 경로, 추천 모듈, 오른쪽 스코프 초안이 바로 바뀝니다.
3. **§2 실적**: 가장 가까운 공개 사례, 시장별 공개 사례, 목표를 공개 실적과 견주어 보기(예측하지 않음).
4. **§3 경로**: 지도에서 시장 순서를 바꾸고, 바뀐 결과를 문장으로 확인합니다. 시장별 데스크 카드, 일정 초안, A/B 비교, 파트너 4탭 "첫 협업 카드"도 여기 있습니다. 기관(트랙 B)은 도입 경로(기준 가중치 → 레이어 범주 → 후보에게 던질 질문)를 봅니다.
5. **§4 스코프**: 모듈(산출물·담당·게이트·근거 사례), 예산대, 6주 차 리포트 미리보기, 90일 차에 갖게 되는 것, 봉인된 항목.
6. **§5 다음 단계**: 우선순위가 매겨진 확인 목록, 작성자와 승인자, 희망 시간(KST), 판아시아에 보낼 이메일 / 내부 메모(KO·EN) / 공유 링크 / Plan ID 복사, 이후 진행 단계.

## 정직성 규칙

- 모든 값에는 출처 등급이 붙습니다: 공개 실적, 공개 자료, 판아시아 관점, 입력값, 예시. 화면 상단의 "출처 보기"를 켜면 전부 드러납니다.
- 고객사 표기가 확인되지 않은 실적($2M 30일 한국 TVL, 15K+ 커뮤니티)은 수치만 보이고 고객사 이름은 어디에도 나오지 않습니다.
- Mantra와 Ondo의 단서 문구는 카드, 이메일, 메모에 원문 그대로 따라갑니다.
- `rates.status`가 `"unset"`이면 가격은 어디에도 나오지 않습니다("Entry Review에서 확정").

## 운영 (CONFIG)

`<script>` 맨 위의 `CONFIG` 하나만 고치면 됩니다. 초안 모드(`meta.mode: "draft"`)에서는 화면 상단 배너에 운영자 확인 항목이 나옵니다. 발송 전에 할 일은 `CONFIG.preflight`에 정리돼 있습니다.

1. 고객사 표기 확인: $2M, 15K+, 1,200+ VIP 옆에 적힌 고객사를 panasia.io에서 확인하고 `attribution`을 정합니다.
2. 규제 조건(KoFIU, MAS, SFC 등)은 URL과 기준일을 넣고 `verified: true`로 바꿔야 "차단"이 됩니다. 그 전에는 모두 "확인 필요"로만 표시됩니다.
3. 가격을 보여주려면 `meta.rates`에 실제 요율 범위를 넣고 `status: "range"`로 바꿉니다.
4. 맞춤 페이지(아웃바운드)는 파일을 복제해 `CONFIG.prospect` 하나만 채우고 `mode: "live"`로 게시한 뒤, `canonicalUrl`에 게시 주소를 넣어 한 번 더 게시합니다.

## 백엔드 연결

`PanasiaAdapter` 객체 하나만 바꾸면 됩니다. `canSubmit: true`와 `submit(payload)`를 구현하면 §5에 "판아시아에 바로 보내기" 버튼이 생깁니다. 지금은 아무것도 전송하지 않고, 사용자가 복사한 텍스트만 밖으로 나갑니다.

claude.ai 아티팩트에서는 `sample` 기능이 있으면 "AI 진단 초안" 블록이 나타납니다. 이 초안은 페이지에 있는 공개 정보만 쓰고, 확인되지 않은 숫자가 섞이면 표시하지 않습니다.
